# me-landing

Портфолио Александра Кузакина в двух версиях: для роли контент-маркетолога и для роли AI-автоматизатора.

## Адреса

- `/` — версия для контента: лонгриды, просмотры, инструменты как усиление текста.
- `/ai/` — версия для AI-автоматизации: инструменты, репозитории, тексты как второй опыт.

Версия выбирается ссылкой, которую владелец отправляет вместе с откликом. Переключателя на самой странице нет — только ссылка на соседнюю версию в правой колонке первого экрана.

## Стек

- Vite + React + TypeScript
- Tailwind CSS v4 (темы на CSS-переменных)
- Motion (анимации появления секций)
- Vitest + Testing Library

## Команды

```bash
npm install
npm run dev     # локальная разработка
npm test        # тесты
npm run lint    # oxlint
npm run build   # сборка в dist/
npm run preview # просмотр собранной версии
```

## Где что лежит

- `src/content/types.ts` — типы контента.
- `src/content/shared.ts` — общие для двух версий факты: статьи, инструменты, опыт, навыки, контакты, подписи разделов.
- `src/content/editor.ts` — тексты версии для контента.
- `src/content/automation.ts` — тексты версии для AI-автоматизации.
- `src/content/index.ts` — выбор версии по `data-edition` на `<html>`; без атрибута открывается версия для контента.
- `src/components/` — секции страницы; порядок задаётся в `order` каждой версии.
- `src/theme.ts` — три темы: `day`, `warm`, `night`; выбор хранится в `localStorage`.
- `index.html`, `ai/index.html` — две точки входа с собственными title, description и Open Graph.
- `docs/superpowers/` — спека и план двух версий.

## Публикация

Сайт опубликован как GitHub Pages user site в корне домена, поэтому `vite.config.ts` использует `base: '/'`. Сборка даёт `dist/index.html` и `dist/ai/index.html`; содержимое `dist/` заливается в корень сайта.
